F12 טול

זע די אינפארמאציע פון יעדן וועבזייטל, פונקט ווי F12 אויף א קאמפיוטער

אויף א קאמפיוטער דריקט מען F12 און מען זעט די „דעוועלאפער טולס": דעם HTML קאוד, ערראָרס, וואס דער זייטל לאדט, קוקיס און נאך.

כראם אויף אנדרויד האט נישט קיין F12. דערפאר מאכט מען איינמאל א בוקמארק מיטן נאמען F12, און פון דאן און ווייטער עפנט עס א פולע דעוועלאפער פענעל אויף יעדן זייטל.

⚡ F12 Lite – פאר גוגל און שטרענגע סייטס

גוגל זייטלעך (למשל NotebookLM, Gmail, Google Docs) און עטליכע אנדערע זייטלעך לאזן נישט אריינלאדן קיין פרעמדע טולס. דארט ווייזט דער פולער F12 די מעלדונג „This site blocks the full tools — use F12 Lite (type F12M)".

דאן ניץ F12 Lite. דער גאנצער קאוד איז אינעווייניג אינעם בוקמארק אליין. ער לאדט גארנישט פון דרויסן, דערפאר ארבעט ער אויך אויף גוגל.

ער ווייזט די זעלבע ℹ️ אינפא: בלאט, זיכערהייט, גיכקייט, אינהאלט, לינקס, סקריפטן און סערוויסעס, סאשעל און סטארעדזש. מיט 📋 קאפירט מען אלעס, מיט ✕ מאכט מען עס צו. (קיין Console, HTML אדער Network האט ער נישט.)

ווייז דעם F12 Lite קאוד

אויב דער קנעפל קאפירט נישט: האלט דעם פינגער אויפן קאוד, „Select all", דערנאך „Copy".

אזוי שטעלט מען עס איין (איינמאל, פונקט ווי אויבן)

  1. דריק 📋 קאפיר דעם F12 Lite קאוד.
  2. דריק ⋮ און דעם שטערן ☆, דערנאך Edit (שריט 2 און 3 אויבן).
  3. ביי Name שרייב F12M. ביי URL מעק אויס אלעס און דריק Paste. דערנאך דריק ←.
  4. אויף א גוגל זייטל: דריק אויפן אדרעס-באר, שרייב F12M, און דריק אויפן ★ F12M בוקמארק אין די ליסטע. נישט Enter.

נאכאמאל F12M, אדער ✕, מאכט עס צו. עס איז נאר צו לייענען: עס ענדערט גארנישט אויפן זייטל און שיקט גארנישט אוועק.

וואס יעדער טאב ווייזט

ℹ️ אינפא

אלע אינפארמאציע, קלאר. עפנט זיך צו ערשט. אלעס אין אפטיילונגען, מען קען יעדע עפענען און צומאכן:

  • 📄 בלאט: טיטל, אדרעס, דאמעין, שפראך, באשרייבונג, שליסל-ווערטער, אייקאן.
  • 🔒 זיכערהייט: צי עס איז HTTPS, און וויפיל קוקיס.
  • ⚡ גיכקייט: לאד-צייט, גרייס פונעם זייטל, וויפיל בקשות.
  • 📝 אינהאלט: די כעפלעך (H1–H3), וויפיל ווערטער, לינקס, בילדער, ווידעאס און פארמען.
  • 🔗 לינקס: אינערליכע און דרויסנדיגע, מיט א ליסטע פון די דרויסנדיגע זייטלעך.
  • 🧩 סקריפטן און סערוויסעס: וועלכע באקאנטע סערוויסעס דער זייטל ניצט (Google Analytics, Facebook Pixel, Cloudflare, jQuery, React, WordPress און נאך), און פון וועלכע דאמעינס עס לאדט.
  • 📣 סאשעל (OG): דער טיטל, בילד און באשרייבונג וואס ווייזן זיך ווען מען שיקט דעם לינק.
  • 💾 סטארעדזש: וויפיל זאכן עס האלט אין localStorage און sessionStorage.

דער 📋 קאפיר אלע אינפא קנעפל קאפירט אלעס ווי טעקסט, צו שיקן אין וואטסעפ.

Console

קאנסאל. די ערראָרס און מעלדונגען פונעם זייטל: רויט איז אן ערראָר, געל א ווארענונג. אונטן קען מען שרייבן א JavaScript קאמאנדע, און זי לויפט אויפן זייטל.

Elements

עלעמענטן (HTML). דער גאנצער HTML בוים פונעם זייטל. דריק אויף א טייל צו זען זיין CSS סטייל, גרייס און אטריבוטן. מיטן 🎯 קנעפל טאפט מען א זאך אויפן זייטל און מען זעט איר קאוד.

Network

נעטווערק. יעדע בקשה וואס דער זייטל שיקט: דער אדרעס, דער סטאטוס (200, 404…), די גרייס, די צייט און די headers. עס ווייזט וואס פאסירט נאכדעם וואס F12 איז אפן.

Resources

רעסורסן. קוקיס, localStorage און sessionStorage, און די ליסטע פון די סקריפטן, CSS און בילדער וואס דער זייטל ניצט.

Sources

קוועלן. דער מקור-קאוד פונעם זייטל און פון זיינע סקריפטן, צו לייענען.

Info

אינפא. דער אדרעס פונעם זייטל, דער User Agent, און אינפארמאציע וועגן דיין טעלעפאן און בראוזער.

Settings

איינשטעלונגען. טונקל אדער ליכטיג, די גרייס פון דער פענעל, און וועלכע טאבן זאלן זיך ווייזן.

גוט צו וויסן

  • עס ארבעט נאר אויף זייטלעך וואס עפענען זיך שוין ביי דיר. עס עפנט נישט קיין פארשפארטע זייטלעך, און עס ענדערט גארנישט אין דיין פילטער.
  • עטליכע זייטלעך (למשל באנקן, וויקיפעדיע, GitHub) לאזן נישט אריינלאדן קיין פרעמדע טולס צוליב זיכערהייט. דאן ווייזט זיך די מעלדונג „This site blocks the full tools — use F12 Lite (type F12M)". דארט ניץ ⚡ F12 Lite (שרייב F12M).
  • נאך א ריפרעש פונעם זייטל גייט F12 צו. קלאפ עס נאכאמאל אן פונעם אדרעס-באר.
  • אלעס ווערט געלייענט פונעם זייטל אליין, אויף דיין טעלעפאן. דער טול שיקט נישט אוועק קיין אינפארמאציע, און ער לאדט גארנישט פון אנדערע זייטלעך.

OS Installation & Migration

Clean Windows and macOS installs, driver setup, software migration and full data transfer from old to new devices.

Request help845-579-2963

Overview

A new computer should feel like an upgrade, not a week of hunting for files and passwords. We move everything that matters (documents, photos, email, browser bookmarks and settings) from your old device to the new one.

When an existing computer is badly infected, corrupted or cluttered, a clean operating system install can give it a fresh start. We handle the install, drivers, updates and your software, then put your data back.

What's included

  • Clean installs of Windows and macOS
  • Correct drivers, firmware and updates
  • Data transfer: documents, photos, desktop, downloads
  • Email accounts, browser bookmarks and saved settings
  • Software reinstallation and licence check
  • Upgrades between operating system versions
  • Secure wiping of the old device, if you're selling or recycling it
  • Final walkthrough of the new setup

Frequently asked questions

Will I need my software licences?

For some programs, yes. Subscription software usually just needs you to sign in. For older licensed software, keep your keys handy, and we'll help you find them where possible.

Can you move data from a Windows PC to a Mac (or back)?

Yes. Documents, photos and most data move across. Some programs are platform-specific and need an alternative, which we'll discuss.

What happens to my old computer?

It's yours. If you're getting rid of it, we can securely wipe it first.

How long does a migration take?

It depends on how much data there is and how many programs need reinstalling. We'll give you an estimate during the assessment.
